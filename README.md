# Kayla Rodriguez — Portfolio

Static site: plain HTML, CSS and JavaScript. No build step. Double-click `index.html` to preview it.

## Folder map
```
index.html            home (hero, work, about, contact)
resume.html           résumé page
projects/             one page per project
style.css             all styling (colors/fonts at the top in :root)
main.js               animations, menu, lightbox
assets/images/        images (current ones are temporary crops of your Notion screenshots)
assets/video/         put .mp4 files here
assets/docs/          put Kayla-Rodriguez-Resume.pdf here
```

## Publish for free (pick one)
- **Netlify Drop:** go to app.netlify.com/drop and drag the whole folder in. You get a live link in about 30 seconds. You can rename it, for example `kaylarodriguez.netlify.app`.
- **GitHub Pages:** upload the folder to a repo, then Settings → Pages → deploy from `main`.
- Optional: buy a custom domain (kaylarodriguez.com or similar) and connect it in either service.

## QR code for your business card
Once you have the live link, make a QR code with any free generator (qr-code-generator.com, or Canva), download it as SVG/PNG at high resolution, and print at least 0.8 in / 2 cm wide. Test it from a phone before you print.

## Tips
- Compress images to about 300–600 KB each (squoosh.app) so pages load fast on conference Wi-Fi.
- Keep video files under about 50 MB, or upload to YouTube/Vimeo and use the iframe snippet.
- Always add `alt` text to new images. It helps accessibility and search.
